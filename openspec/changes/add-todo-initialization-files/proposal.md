## Why

当前 TODO 任务文件夹只自动维护 `README.md`，用户想为每个任务预置固定说明、约束或提示词时，需要手动复制文件，容易遗漏且内容不一致。增加全局初始化文件模板后，创建 TODO 时可以选择要随任务携带的文本文件，并在任务文件夹创建时自动落盘。

## What Changes

- 增加全局初始化文件模板配置，每个模板包含名称、描述、文件名、文本内容和是否默认选择。
- 创建 TODO 时展示全局模板的名称、描述和文件名；默认选择的模板自动勾选，非默认模板允许用户手动勾选。
- 创建 TODO 后保存已选初始化文件的快照，避免后续全局模板修改影响已创建 TODO。
- 当 TODO 任务文件夹创建时，在该文件夹内按快照创建同名文本文件，文件内容与快照内容一致。
- 保留现有 `README.md` 自动生成行为，初始化文件不替代 `README.md`。

## Capabilities

### New Capabilities

- `todo-initialization-files`: 管理全局 TODO 初始化文件模板，并在创建 TODO 与准备任务文件夹时应用所选模板。

### Modified Capabilities

- None.

## Impact

- 后端设置持久化：扩展全局设置或新增配置存储，用于保存初始化文件模板。
- 后端 TODO 数据模型：保存创建 TODO 时选中的初始化文件快照。
- 后端任务工作区准备流程：在任务文件夹创建或确保存在时写入选中的初始化文本文件。
- Wails API：提供读取和保存初始化文件模板的接口，并扩展创建 TODO 请求。
- 前端设置界面：增加初始化文件模板的增删改配置入口。
- 前端 TODO 创建表单：展示模板列表并提交用户选择。
- 测试：覆盖模板持久化、TODO 创建快照、任务文件夹写入、默认选择和手动选择交互。
