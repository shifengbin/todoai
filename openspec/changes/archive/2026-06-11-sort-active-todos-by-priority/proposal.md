## Why

当前活动 TODO 列表按持久化数组顺序展示，新建和不同优先级的任务混在一起时，高优先级任务不一定出现在用户最容易看到的位置。默认按优先级排序可以让用户打开 TODO tab 时先处理更重要的活动任务。

## What Changes

- 活动 TODO 列表提供排序切换控件，支持按优先级排序和按创建时间排序。
- 默认选择优先级排序，顺序为 `高`、`中`、`低`，相同优先级内按创建时间 `createdAt` 正序展示，先创建的在上。
- 时间排序按 `createdAt` 创建时间正序展示，先创建的在上。
- 归档 TODO 列表保持现有展示顺序，不受活动 TODO 排序规则影响。
- 排序选择仅影响当前前端会话，不改变 TODO 持久化数据结构或后端 API。

## Capabilities

### New Capabilities

- None

### Modified Capabilities

- `todo-workspace`: 活动 TODO 列表新增排序切换，并默认按优先级和创建时间确定展示顺序。

## Impact

- 前端 TODO 侧边栏活动列表排序状态、切换控件和派生顺序。
- 前端组件测试需要覆盖优先级排序、同优先级创建时间排序、时间排序切换，以及归档列表不受影响。
- 后端 TODO 模型、持久化格式和 Wails API 不需要变更。
