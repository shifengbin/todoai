## Context

当前 `frontend/src/App.vue` 通过一套共享的浮层状态和事件函数展示生命周期脚本参数帮助。创建 TODO 表单和全局生命周期脚本管理界面各自提供一个问号按钮，按钮触发同一个浮层。创建 TODO 的用户只填写参数值，不负责定义占位符语法，因此该入口需要从创建流程移除；全局脚本管理仍需为模板配置者保留使用说明。

创建表单中的参数标题、参数输入项、描述、默认值和必填状态均与帮助按钮相互独立。后端参数模型、快照持久化和脚本渲染也不依赖该按钮。

## Goals / Non-Goals

**Goals:**

- 移除创建 TODO 表单生命周期脚本参数标题旁的问号按钮及其可触发的浮层。
- 保持创建 TODO 时生命周期脚本参数的展示、录入、校验和提交行为不变。
- 保持全局生命周期脚本管理中的参数帮助按钮及浮层行为不变。
- 通过前端测试明确区分创建流程与脚本管理流程的帮助入口行为。

**Non-Goals:**

- 不修改参数帮助文案、浮层样式或定位算法。
- 不移除全局生命周期脚本管理中的参数帮助功能。
- 不修改参数定义、参数值快照、后端校验或脚本占位符渲染。
- 不重新设计创建 TODO 表单的其他字段或布局。

## Decisions

### 仅删除创建表单专用的帮助按钮模板

从创建 TODO 参数标题区域删除 `todo-lifecycle-script-parameter-help-create` 按钮及其事件绑定，保留“参数”标题和参数字段。共享的帮助浮层、状态、显示/隐藏函数、图标导入和样式继续保留，因为全局脚本管理仍在使用它们。

备选方案是在 CSS 中隐藏创建表单按钮。该方案仍会保留无效的 DOM、可访问性属性和事件绑定，使实现与行为规范不一致，因此不采用。另一个方案是删除整套参数帮助逻辑，但会破坏全局脚本管理的既有要求，因此不采用。

### 保持现有标题容器和共享样式

创建表单的 `lifecycle-script-parameter-heading` 容器继续承载“参数”标题。帮助按钮相关样式仍被全局脚本管理使用，不进行样式清理，以避免扩大变更范围。

### 将创建流程测试改为不存在性验证

移除当前“创建 TODO 时显示参数帮助”的正向交互测试，改为在选择带参数脚本后断言创建表单不存在专用帮助按钮，同时继续验证参数字段可见、默认值和提交值正确。全局脚本管理的帮助浮层测试保留，用于防止共享帮助功能被误删。

## Risks / Trade-offs

- [误删共享帮助状态或浮层，导致全局脚本管理帮助失效] → 只删除创建表单专用模板节点，并保留全局管理帮助测试。
- [参数标题只剩一个子元素后出现布局变化] → 保留现有标题容器，并在前端测试后进行创建 TODO 表单的轻量人工检查。
- [测试只验证按钮不存在，未覆盖参数功能回归] → 继续运行现有参数展示、默认值、必填校验和提交测试。

## Migration Plan

该变更不涉及数据迁移或兼容处理。发布时随前端资源直接生效；如需回滚，恢复创建表单的帮助按钮模板和对应测试即可。
