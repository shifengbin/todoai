## ADDED Requirements

### Requirement: Todo 分支候选框离开输入区域后关闭
系统 SHALL 在 Todo 分支输入框失焦时关闭当前分支候选框，并 MUST 保留用户已经输入的分支值。

#### Scenario: 创建 Todo 时手动输入自定义分支后点击其他位置
- **WHEN** 用户在创建 Todo 弹窗中选择项目、输入不在候选列表中的自定义分支，并点击分支输入框以外的位置
- **THEN** 系统关闭该项目的分支候选框，并保留输入框中的自定义分支值

#### Scenario: 编辑 Todo 时手动输入自定义分支后点击其他位置
- **WHEN** 用户在编辑 Todo 弹窗中修改项目分支为自定义值，并点击分支输入框以外的位置
- **THEN** 系统关闭该项目的分支候选框，并保留输入框中的自定义分支值

#### Scenario: 给 Todo 添加项目时手动输入自定义分支后点击其他位置
- **WHEN** 用户在添加项目到 Todo 弹窗中选择项目、输入自定义分支，并点击分支输入框以外的位置
- **THEN** 系统关闭该项目的分支候选框，并保留输入框中的自定义分支值

#### Scenario: 选择候选分支
- **WHEN** 用户点击分支候选框中的候选分支
- **THEN** 系统设置该项目的分支值并关闭分支候选框

### Requirement: Todo 任务列表滚动条不得遮盖行操作按钮
系统 SHALL 为 Todo 任务列表滚动区域预留稳定的滚动条空间，使滚动条出现时 MUST NOT 遮盖 Todo 行右侧操作按钮。

#### Scenario: 任务列表出现纵向滚动条
- **WHEN** Todo 任务列表内容高度超过侧边栏可视区域并出现纵向滚动条
- **THEN** Todo 行右侧操作按钮仍位于滚动条左侧的可点击区域内

#### Scenario: 任务列表未出现纵向滚动条
- **WHEN** Todo 任务列表内容未超过侧边栏可视区域
- **THEN** Todo 行右侧操作按钮布局保持稳定，不因滚动条空间预留产生不可用或重叠状态

#### Scenario: Todo 弹窗打开时
- **WHEN** 用户打开创建 Todo、编辑 Todo 或添加项目到 Todo 的弹窗
- **THEN** 系统隐藏任务列表滚动条，避免滚动条显示在弹窗或遮罩层上
