## Why

当前工作区只显示项目名称、路径和终端区域，用户需要切回终端或外部工具才能确认当前项目的 Git 分支和改动数量。底部状态栏可以让用户在操作终端时持续看到当前项目的仓库状态，降低误操作分支或遗漏未提交改动的风险。

## What Changes

- 在主工作区底部添加固定高度状态栏，展示当前激活项目的 Git 信息。
- 状态栏展示当前分支名、已修改文件数量，并为非 Git 仓库或不可用项目提供明确的空状态。
- 新增后端运行时查询能力，用当前项目路径读取 Git 状态，不把 Git 信息写入项目持久化配置。
- 在项目切换、应用启动、终端命令结束和窗口重新获得焦点时刷新当前项目的 Git 状态。
- 保持终端区域高度稳定，避免状态信息出现或消失时造成 xterm 反复抖动。

## Impact

- 后端：新增 Git 状态查询模型和 Wails 绑定方法，使用项目路径执行受限的 `git status` 查询。
- 前端：更新 `App.vue` 主布局、状态栏渲染逻辑、刷新触发点和相关样式。
- 测试：增加 Go 单元测试覆盖 Git 状态解析、非仓库目录和错误处理；增加 Vue 单元测试覆盖状态栏展示与刷新调用。
- 构建：需要更新或确认 Wails 生成绑定和前端类型模型。
