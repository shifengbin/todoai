## Why

项目库删除目前使用浏览器原生确认框，确认位置脱离项目行上下文，和 TODO 区域已有的气泡确认体验不一致。项目库也只能逐个删除项目，用户整理大量导入项目时操作成本较高。

## What Changes

- 项目库中的单项删除改为删除按钮旁的气泡确认，不再使用 `window.confirm`。
- 项目库项目行支持勾选，用户可选择一个或多个项目。
- 项目库顶部增加“删除选中”批量操作，未勾选项目时不可执行。
- 批量删除执行前显示顶部确认气泡，并在确认后删除所有选中项目。
- 删除项目仍只移除应用内项目记录、TODO 活动关联和相关运行时终端，不删除磁盘文件，也不影响 archived TODO 快照。

## Impact

- 前端：`ProjectSidebar.vue` 项目库行、顶部操作栏、确认气泡状态和相关样式；`App.vue` 项目删除调用路径。
- 后端/API：新增或扩展项目批量删除接口，复用现有项目删除语义并统一清理对应终端。
- Wails 绑定：新增批量删除方法后需要重新生成或同步前端绑定声明。
- 测试：更新侧栏组件测试、App 前端集成测试、Go 后端项目删除和 App API 测试。
